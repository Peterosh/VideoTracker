VideoTracker Privacy Policy / 剧迹隐私政策

Last updated / 最后更新：2026-11-18

English

VideoTracker records episodic video progress and syncs watch history through Chromium browser-sync extension storage. No separate VideoTracker account or application server is used.

Stored data

  • Video page title and URL.
  • Show name, episode, playback position, duration, progress, and timestamps.
  • Device display name, browser, and operating-system platform.
  • Optional LAN and public IP addresses, only after network information is enabled by the user.

Network information

LAN IP detection uses browser-local WebRTC candidates. Public IP lookup contacts api64.ipify.org, api.ipify.org, and api.myip.com only when the optional feature is enabled. These services receive the ordinary HTTPS request IP. Watch records, page titles, device names, and credentials are not sent with that request.

Storage and sharing

Records are stored locally and in browser-sync extension storage. Browser sync may transfer extension data between devices signed into the same browser account. VideoTracker does not sell user data, use it for advertising, or share it with analytics providers.

Controls

Users can disable network information collection, delete episode or show records, export a JSON backup, remove local records, and uninstall the extension.

中文

剧迹用于记录连续剧观看进度，并通过 Chromium 浏览器同步扩展存储在不同设备间同步观看历史。剧迹不提供独立账户系统，也不运营额外的应用服务器。

保存的数据

  • 视频页面标题和 URL。
  • 剧名、集数、播放位置、总时长、进度和时间。
  • 设备显示名称、浏览器和操作系统平台。
  • 仅在用户主动开启网络信息功能后，才获取局域网和公网 IP。

网络信息

局域网 IP 通过浏览器本地 WebRTC candidate 获取。只有开启可选功能后，才会通过 api64.ipify.org、api.ipify.org 和 api.myip.com 查询公网 IP。第三方服务会看到普通 HTTPS 请求的公网 IP，但不会收到观看记录、页面标题、设备名称或账户凭据。

存储与共享

记录保存在本地和浏览器同步扩展存储中。浏览器同步可能会在登录同一浏览器账户的设备之间传输扩展数据。剧迹不会出售用户数据、用于广告或提供给分析服务商。

用户控制

用户可以关闭网络信息采集、删除单集或整部剧记录、导出 JSON 备份、删除本地记录并卸载扩展。
