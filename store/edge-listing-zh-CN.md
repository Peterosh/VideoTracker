# Microsoft Edge Add-ons 商店资料（中文）

## 名称

剧迹 - VideoTracker

## 简短描述

记录连续剧和动漫看到第几集、当前播放分钟，并通过浏览器账户在不同设备间同步观看记录。

## 完整描述

剧迹是一款为连续剧和动漫观看记录设计的浏览器扩展。扩展可以自动识别网页中的 HTML5 视频播放器，包括位于 iframe 中的播放器，并记录当前剧名、集数、播放位置、视频时长和观看时间。

扩展弹窗提供“当前视频”和“追踪列表”两个页签，可以直接开始或停止追踪、搜索已追踪剧集并立即同步。管理页面提供“观看记录”和“设备列表”两个独立视图，支持搜索、筛选、置顶常看剧集、继续观看、删除单集、删除整部剧、编辑设备名称以及导出和导入 JSON 备份。

观看数据首先保存在浏览器的本地存储中，并通过 Chromium 的浏览器同步扩展存储与同一浏览器账户中的其他设备同步。同步时会先读取并合并云端数据，只在本地记录更新时间更新时回传，减少旧数据覆盖新数据的风险。管理页面提供手动同步按钮，并显示本地与云端是否已经对齐。

广告期间不会覆盖正片进度。扩展会识别常见广告提示、腾讯视频短广告、视频源变化和异常时长，并在播放内容稳定后恢复记录。

管理页右上角提供网络信息开关和中英文下拉菜单。设备列表允许用户修改设备名称。局域网 IP 和公网 IP 属于可选的网络信息功能，默认关闭，只有用户主动开启后才会获取。关闭该功能后，不会继续采集或保存新的网络地址。

剧迹不提供独立账户，不投放广告，不出售用户数据，也不包含远程执行代码。

## 单一用途

记录视频观看进度，并在用户自己的同步浏览器账户设备之间同步观看历史。

## 权限用途

- `tabs`：读取当前标签页的标题、URL、声音状态和活动状态，用于识别正在观看的视频。
- `scripting`：在用户开始追踪后按需检查视频页所有 frame 中的标准 HTML5 视频，不常驻内容脚本。
- `storage`：保存本地观看记录、浏览器同步记录、设备设置和活动状态。
- `alarms`：定期更新已追踪视频的播放进度并执行同步检查。
- `activeTab`：读取用户主动选择的当前视频页。
- `http://*/*`、`https://*/*`：支持未预先枚举的视频网站以及跨域 iframe 播放器。扩展只在视频页面或用户追踪的页面中检测标准 HTML5 视频。

## 远程代码

不使用远程代码。

## 数据使用

保存页面标题、URL、剧名、集数、播放位置、视频时长、观看时间、设备名称、浏览器和系统平台。局域网与公网 IP 为可选数据，默认关闭。

数据仅用于观看记录、播放进度恢复和用户自己的浏览器账户同步，不用于广告或出售。
