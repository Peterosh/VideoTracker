# 剧迹 - VideoTracker

一个兼容 Microsoft Edge 和 Google Chrome 的浏览器扩展，用于记录连续剧和动漫看到第几集、当前看到多少分钟，并在不同设备间同步观看记录。

## 功能

- 自动识别当前视频页中的 HTML5 视频、剧名、集数和播放时间，包括 iframe 中的播放器。
- 扩展弹窗提供“当前视频”和“追踪列表”两个页签，可直接开始或停止追踪、搜索记录并立即同步。
- 一键开始或停止追踪当前剧集。
- 已保存的剧集在新标签页或浏览器重启后再次播放时，会自动恢复追踪；用户主动停止后不会被自动恢复。
- 自动保存播放位置，并在切换集数时更新记录。
- 视频自然播放达到 80% 时视为本集看完，跳过片尾曲也能正确标记；直接拖动到结尾不会误判。
- 自动过滤播放器广告提示、腾讯短视频广告和视频源突变，广告期间不写入观看进度。
- 管理页面可以查看每一集的观看位置、总时长、进度、观看时间和完成状态。
- 管理页面提供“观看记录”和“设备列表”两个独立视图，右上角可切换中英文和网络信息功能。
- 分集记录会保存观看设备名称、浏览器、系统、局域网 IP 和公网 IP。
- 支持中文和英文界面，并跟随浏览器语言自动切换。
- 局域网 IP 和公网 IP 默认关闭，需要用户在管理页右上角主动开启网络信息功能。
- 支持手动修改剧名、集数、设备名称和集数识别方式。
- 支持删除整部剧或单独删除某一集记录。
- 支持置顶常看剧集，置顶记录会排在观看记录列表前面。
- 本地保存完整记录，并通过当前浏览器账户与云端存储同步。
- 同步时先拉取云端记录并合并，只有本地记录更新时才上传，避免旧数据覆盖云端新数据。
- 支持手动立即同步，并显示本地与云端是否已经对齐。
- 支持导出和导入 JSON 备份。
- 单集进度回退或切回更小集数时，需要连续观看满 1 分钟才更新，避免播放器加载或自动跳转改写记录。

## 安装

### Microsoft Edge

1. 打开 `edge://extensions/`。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择项目目录。

### Google Chrome

1. 打开 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择项目目录。

安装后请保持一个扩展副本。更新时点击“重新加载”，不要从不同目录重复安装。

## 使用

### 开始追踪

1. 打开视频播放页面并开始播放。
2. 点击浏览器工具栏中的“剧迹”图标。
3. 检查自动识别的剧名和集数，需要时可以手动修改。
4. 点击“开始追踪”。
5. 播放过程中扩展会自动保存当前集数和播放位置。

### 管理观看记录

1. 点击扩展弹窗右上角的列表图标进入管理页面。
2. 在左侧选择剧集。
3. 查看每一集的播放位置、总时长、进度和观看设备。
4. 使用“全部”“观看中”“已看完”筛选记录。
5. 点击单集右侧按钮打开播放页面或删除该集记录。
6. 点击“删除剧集”可以删除整部剧和它的全部分集记录。
7. 点击剧集右侧的图钉按钮可以置顶或取消置顶。

### 同步

1. 使用同一个 Edge 或 Chrome 账户登录不同设备。
2. 开启浏览器同步。
3. 在管理页面或扩展弹窗右上角点击“立即同步”。
4. 显示“本地与云端已对齐”时，本地记录和同步存储已经一致。

### 设备名称

1. 点击管理页顶部的“设备列表”。
2. 直接修改设备名称。
3. 修改后的名称会同步到其他设备。

### 显示设置

1. 使用管理页右上角的语言下拉菜单切换中文或英文界面。
2. 使用右上角的“网络信息”开关控制局域网 IP 和公网 IP 的获取。

### 备份

- 点击“导出备份”保存当前全部剧集和分集记录。
- 点击“导入备份”选择之前导出的 JSON 文件，记录会按更新时间合并。
